# Reaper Cleaner

Годовой проект по программированию. Игра на Python + pygame.

## Концепция
Жнец-стажёр зачищает круги ада. Top-down action, вдохновлённый The Binding of Isaac и Enter the Gungeon.

## Управление
- WASD — движение
- Мышь — прицеливание
- ЛКМ — удар косой
- ПКМ — заряд и выпуск самонаводящихся лучей из гримуара

## Алгоритмы
- Процедурная генерация этажа (размещение комнат, проверка связности BFS)
- A* для перемещения врагов
- k ближайших соседей (kNN) для наведения лучей гримуара

## Установка и запуск
```bash
pip install -r requirements.txt
python main.py
